# Plate kit: how to use it (11/04/2026)

Parts: `site/assets/js/plate-svg.js` (SVG marks) then `plate.js` (everything else), the Plate kit block in `site.css`, `scripts/build_plates.py`. Builders do not edit these.
Working examples: `work/site-refresh/tmp/plate-demo/` (14 plates, one page script). Rough definitions of 20 of the 21 planned plates (all but `dc-iea-world`, the same form as `dc-lbnl-us`), which already build on the real claims: `work/site-refresh/tmp/kit-proof/*.json` (placeholder wording and some claim choices; copy and correct against the architecture).

## A page
```html
<link rel="stylesheet" href="../assets/css/site.css"> <link rel="stylesheet" href="../assets/css/dc.css">  <!-- page CSS (dc.css, ai.css, ru.css) is the builder's, after site.css -->
<script defer src="../assets/js/plate-svg.js"></script><script defer src="../assets/js/plate.js"></script><script defer src="../assets/js/data-centers.js"></script>
<nav class="section-strip" data-workbench aria-label="Sections"><div class="wrap"><ul><li><a href="#jobs">Jobs</a></li></ul></div></nav>
<section id="jobs" class="section panel"><div class="wrap"><h2 class="panel-title">Jobs</h2> <!-- plate:dc-jobs-per-mw --><!-- /plate:dc-jobs-per-mw --> <div class="disclosure-grid"><details class="disclosure">...</details></div></div></section>
```
Links become tabs: arrows, Home, End, hash deep links (a hash inside a panel opens it; `#checklists` also opens the first `<details>` in it). `?ID-view=sources` or `table` opens a plate on that view, from a link on another page. `.panel` keeps the base ground and no top padding, so the plate starts under the strip. The first plate on the screen runs at least to the window's foot by itself; others take at least 72vh, or the window with `"fit": true`. A zone that needs more grows the plate, in the page's scroll. Below 1100px the zones stack.
Build: `python scripts/build_plates.py --page data-centers/index.html` writes only that page and ignores other builders' plates mid-edit. Never edit between markers. Check: `python scripts/validate_public.py`.
Zones, built for you: `.plate-claim` (eyebrow, title, subtitle, text, controls, foot), `.plate-plot` (one focus stop), `.plate-under` (the key, and a ruler's caption if it redraws), `.plate-detail` (the one raised thing; Reading, Sources (N), Table: readout, Reading, facts, Copy, Reset, and one line of receipts; chips, the open receipt, and the list live in Sources). A wide Table view widens its zone. In a workbench panel the claim zone keeps its title, its controls, and one paragraph; the rest reads under the plate, in the details grid that follows it or a new one in the page's style (`moveProse`): a paragraph of several sentences as a disclosure whose summary is its first, a single sentence or a foot line as a ruled `.plate-note`. A foot that is only a link stays. Every figure list in the detail keys its rows with `.plate-square`: grey, hollow when modeled, orange only for the selected series among several. `.plate-key`, the dash, stays in plot legends that sample a line. No scripts: all views show, the plate has no least height, the setting line names the default, and the parts stay where the build wrote them.

## Plate file: `site/data/plates/ID.json`
| Key | Means |
|---|---|
| `schema`, `tier`, `id`, `page` | `1`, `"T0"`, the file name (not a tab panel's id), the page path under `site/` |
| `title` (required), `subtitle`, `text` (list), `eyebrow` | Title is the finding at the default setting: one clause and one figure pair, at most four lines at 1440 in the claim column. The build warns past 120 characters. A date or edition tail goes in the eyebrow ("The same hour, modeled 11/2026") and the rest in the subtitle. Digits only through placeholders (below) |
| `plot.type` | `ladder`, `bars`, `lines`, `multiples`, `instrument`, `matrix`, `map` |
| `plot.scale`, `plot.domain`, `plot.units` | `log` (rulers with squares only) or `linear`; a domain that would clip fails; `units` renames, `{"Wh/hour": "Wh"}`, never converts |
| `plot.highlight`, `plot.highlight_by` | The lead series, or a segmented control whose stop values are series names |
| `plot.projected_from`, `plot.projected` | Year the dashes start (lines); every mark a projection (rulers: hollow, dashed range, a dashed cap on bars) |
| `plot.fit`, `plot.off_ruler` | `"data"`: a log ruler in whole decades around the rows and ticks this stop counts, redrawn at each stop; its "ten times" caption moves under the axis. `off_ruler: ["household"]`: those rows stay out of it and print `28,740 (off this ruler) Wh`. `domain` still sizes the no-script ruler and must hold every number |
| `plot.switch` | The name of the control to move out of the claim and over the plot, at its full width (`.plate-switch`) |
| `plot.yard` | Row ids that are yardsticks: half the height of the others, at least 56px with a one-line label (`.has-yard`, `.is-yard`), and out of `plot.shared`. A list on `plot` because the build copies plot keys through and drops unknown row keys |
| `plot.shared` | `{"word": "lighter", "at": {"whole": "the whole hour"}}`: draws `.ladder-shared` across the selected row and the rows whose ranges overlap it, and adds one sentence to the Reading: "At the whole hour, chat and streamed video overlap (9.3 to 24 against 7.2 to 203); neither is clearly lighter." Never a ratio. A plate opts in, because a shared band claims the rows measure one thing. `at` maps stops to words; without one it says "this setting" |
| `plot.needle` | On an instrument, a row id: one needle stands at that row's place across every row, whichever is selected. It has no label: the row it stands on names it |
| `plot.signed`, `plot.axis_label` | Print + on positives; a caption over a ruler with no group label |
| `rows`, `controls`, `by` | Below. `by` names a segmented control whose stops switch a row's numbers (not for bars, instrument, matrix) |
| `default`, `fit` | Selected key (default: first row, or the lead series' latest year); `true` makes a plate further down fill the window |
| `boundary`, `reading`, `reading_group`, `tail` | Short boundary sentence; template per row; one template per key (below); a sentence after them |
| `inputs`, `model`, `fields` | Named numbers and per-row formulas (below). `model` names a file in `site/data/`, here `comparison-model` |
| `also`, `details`, `cites`, `limits`, `foot`, `more`, `not_counted`, `gap` | Figures beside the plot; plain sentences in the detail, always; extra receipts; `{"fp-022": "public sentence"}` for a cited partly claim; `[{"text", "href", "link"}]`; More-assumptions summary; words for a row off at a stop; words for a missing group value |
| `table` | Below. Default columns are Row, Setting, Value, Year, Source |

**Controls.** Names are unique on a page and appear in the address. `{"type": "segmented", "name", "label", "default", "options": [{"value", "label", "is": "input-or-control-name"}]}` (a toggle is two stops; `is` makes a stop stand for that number in formulas, and a stop with none is then blank, so a row prints its `gap`). `{"type": "range", "name", "label", "min", "max", "step", "default", "presets": [2.52, 10]}` (range and typed twin; presets may sit off the step). `{"type": "number", "name", "label", "min", "max", "step"}` (typed alone; no default means blank). `"more": true` puts a control in the More assumptions disclosure.

**Rows, any kind.** Every number comes from a claim, a model, or a formula; a row with no claim fails. Optional: `cites` (more claim ids, all receipts show), `note` ("Assumption: ..."), `equation` ("Equation: ..."), `detail` (a plain sentence when selected), `boundary`, `modeled` (hollow; default: source kind `model`, and every formula row), `gap` (words for a claim with no number; default "No public measurement"), `range: false` (drop a claim's low and high when they are not its range), `range_from: "id"` (take them from another claim, cited), `negate: true` (a shortfall of 19 reads -19), `convert: {"times": 3.78541, "to": "megaliters"}` plus optional `digits` (fails unless the claim's `derived` holds the arithmetic), `also: [...]` (shown when this row is selected), `tag`, `cols: {"overhead": "GPU only"}` (words for a table column). **A partly claim needs `limit`** (on the row, on the claim, or in the plate's `limits`), one public sentence, or the build fails. It reaches the receipt and Sources, and the Reading for a row's main claim.

## The kinds
**`ladder`**: rows with one mark on a shared ruler, as an HTML list; CSS places the marks, so it needs no redraw and prints as is. `{"id": "kebab", "label": "...", "claim": "fp-001"}`, or `"claims": {"stop": "id" or null}` with `by` (null prints `not_counted`). Options on `plot`:
- `groups: [{"id": "use", "label": "Basis stated here", "domain": [0, 1.5], "mark": "bar"}, {"id": "draw", "label": "..."}]` plus `"group": "use"` on rows: **two rulers in one plate**, own axis and unit each; `mark` is `square` or `bar`; keys cross them.
- `count: {"unit": "input-name", "noun": "text prompt", "nouns": "text prompts", "cap": 200}`: **Count view**, adds its own Ruler | Count control; one square per unit up to the cap, remainder printed. Scripts only; the table holds the numbers.
- `marks: [{"id", "label", "claim": "id"} or {"id", "label", "value": "formula", "unit": "Wh", "low", "high", "when": {"control": "stop"}, "group": "id"}]`: labeled ticks (yardstick, baseline); `when` shows one per stop.
- `sort: "control"`: a segmented control with stops `value` (biggest first) and `tag` (tagged rows together) reorders rows and keys.
- **Dumbbell**: `{"id", "label", "pair": [{"id": "capex", "name": "Capital spending", "claim": "fin-003", "points": "series_fiscal_year_ends"}, {"id": "cash", "name": "...", ...}]}` with `by` on a control whose stop values are years or `latest`. Legend and both values are automatic. A member may name `"claims": {"2023": "dem-119", "2019": null}` by stop (null: a ghost there), and a pair with neither `claims` nor `points` stands at every stop.
- **A checked pair**: a projection and what came after, for one target year on one boundary. `"check": "level"` on the row computes, from the two figures, later minus earlier and that as a percent of the later figure; `"growth"` gives the difference in percentage points and no percent, for a rate near zero; `{"diff": "dem-108", "ape": "dem-109"}` reads both from claims, cites them, and fails if the claim is not the pair's difference. The row's end and the readout print the signed difference, without scripts too, and `{diff}`, `{diff_unit}`, `{error}`, `{ran}` (high or low), and `{cell}` reach `reading_group`, `reading_for`, and table columns. A page script keeps the row's end and the readout at each stop (`dc-forecast-check` in `data-centers.js`). `"tag"` may be `{"stop": "words"}`.
- `plot.key: [{"shape": "diamond", "label": "Projection"}, {"label": "Words alone"}]`: a key of the plate's own marks in place of the automatic one; the page's sheet draws `.plate-square.is-diamond`. `table: {"pairs": true, "columns": [...]}`: one table line per pair, the first member's fields plus `later`, the second's figure, and both claims. `"select": "point"` on a ladder takes the needle away and keeps a mark's label from jumping with the selection; the page's sheet hides the static needle.

**`bars`**: a ladder whose marks are bars from zero: same rows, `groups`, `marks`, `sort`. Negatives make it diverging (slot 1 and 2, neutral zero); add `signed`. No `by`, no needle, no log. A `group` on a ladder may also be `"mark": "bar"`.

**`lines`**: `{"series": "Google", "claim": "rs-001", "points": "series"}`; `points` names a claim field holding `{year: value}` (resources) or a list of periods with `end` and one number (`series_fiscal_year_ends`, which also gives `{end}`). No `points`: one point at the claim's `year`, or `"x": 2027`. A range-only claim draws a range line; `"dx": 10` shifts it aside. Selection is the year; the needle snaps; facts list every series. A one-point series always shows its square.
- `band`: `{"low": "series", "high": "series"}`, `{"across": "series"}` (lowest to highest at each year), or `{"across": "range"}` (each point's own low and high), plus `"band_label"`. A 10 percent wash, dashed edges past `projected_from`. Templates get `{band_low}`, `{band_high}`.

**`multiples`**: as lines, one cell per series on one axis. With `panels: [{"id": "capex", "label": "Capital spending"}]` and `"panel": "capex"` on rows: one cell per panel, each with **its own axis and unit**; `axis: "shared"` to share. With `highlight_by` the facts, receipts, and label follow the picked company. `select: "point"` (rows then need `id`) makes every point its own selection: no needle, squares always on.

**`instrument`**: `plot: {"type": "instrument", "groups": [{"id": "ctx", "label": "Context, fixed"}]}`. Output rows are ruled rows, a large figure on a thin ruler running to what the formula reaches at the settings' maximum (or `"domain": [0, 40]`):
```json
{"id": "twh", "label": "Energy a year", "unit": "TWh", "digits": 2, "formula": {"value": "amw * 8.76 / 1000"}, "equation": "TWh = aMW x 8.76 / 1000"}
{"id": "site", "label": "Site water", "unit": "million liters", "formula": {"low": "twh * ifblank(own, ms) * 1000", "high": "twh * ifblank(own, lbnl) * 1000"}}
{"id": "plant", "label": "Water at the plant", "unit": "million liters", "formula": {"value": "twh * gen * 1000"}, "show": {"count_plant": "on"}, "gap": "Off: the convention is unstated"}
```
Fixed rows below a `"group": "ctx"`: `{"id", "label", "claim"}`, `{"id", "label", "figures": [{"claim": "jb-073", "name": "permanent jobs"}]}`, or a sparkline `{"id", "label", "spark": ["jb-041", "jb-042"]}` (claim ids, or `"claim"` with a series field name). The plate's `reading` serves formula rows; fixed rows keep a row's own sentence.

**`matrix`**: `plot: {"type": "matrix", "columns": [{"id": "national", "label": "National scale"}, {"id": "open", "label": "Open question"}]}`, `default: "water--national"`. `{"id": "water", "label": "Water", "cells": {"national": [{"claim": "tr-001", "say": "about {display} on site", "modeled": true}], "open": "Watershed and season"}}`. A list holds figures with evidence squares; a string is words. Keys are `row--column`. Arrows move in two dimensions. Sentences get `{column}`; `reading_words` is the word-cell template.

**`map`** (prototype, 11/06/2026, `dc-project-map`): rows as on a ladder (`{"id", "label", "claim"}`), drawn as one tile a county on the county drawing `scripts/build_project_map.py` writes at the top of the page's `main`: a sprite of `co-FIPS` and `st-xx` paths and a `county-layout` block (state names, and one tile a named county, keyed as the rows are, with a line back where a tile was pushed off its county). Run it before the plates. A tile prints its row's figure; a county with no row is an outline. `plot.map: "steps"` on a ladder draws the same map over it, counties filled on five steps of ink across the ruler's domain; a page script then shows one form at a time with the `hidden` attribute, which tells `plate.js` which marks are the options (`dc-climate-counties`, its `cc_form` switch). The tiles are the list box's options, with no new keys. A page script sets `--k` on the plot to keep a tile 20px at any width and moves the county wash with the selection (`countyMap` in `data-centers.js`); print and no scripts show the default picked at `--k` 1.5.

## Numbers in sentences and formulas
**Templates** (`title`, `subtitle`, `text`, `tail`, `reading`, `foot`, `say`): `{label} {series} {panel} {column} {display} {text} {unit} {value} {low} {high} {year} {end} {boundary} {evidence} {source} {published} {limit}`, from the default row outside `reading`. Any row by id `{amw[text]}`; any claim `{c[dem-058][display]}`, `{c[dem-001][series][2030]:.0f}`, `{c[dem-073][value]:,.0f}` (joins the receipts); an input `{region}` or model branch `{now[chat][total]:.1f}`; a setting `{mw}` (a segmented stop prints its label); a field `{share}`. Python format specs work. In `reading`, these stay live and refill when a setting moves.
A typed digit fails the build, so a number on the page always comes from a claim. Allowed: years, MM/YYYY and MM/DD/YYYY dates, `#2026-039`, `Scope 2`, names glued to digits (`CO2`, `GPT-5`, `FY2026`, `AEO2026`). Spell small words ("ten text prompts"). Row labels, notes, equations, marks, and limits are exempt.
**`reading_group`**: one sentence per key instead of one per row, with `{capex}` for each panel id or pair member id (its `text`, or the plate's `gap`), plus the first row's fields: `"{series}, fiscal {year} (ends {end}): capex {capex}, cash {cash}, USD billion."`
**`inputs`**: `{"region": {"claim": "dem-058"}, "lo": {"claim": "jb-023", "field": "low"}, "now": {"model": "computed_defaults.same_hour.default"}}`. A model branch arrives as numbers only, prose dropped. Claim inputs cite themselves on any row that reads them; model branches do not, so list the claims in `cites`.
**`formula`**: numbers, names (dots reach into a branch), `+ - * / ( )`, `min`, `max`, `ifblank(a, b)`. A blank gives a blank. Names: inputs, controls, earlier rows by id (`amw`, `site_low`, `site_high`; such ids need no dash). `digits` is significant figures; by default two, three at 99.5 and above, the Explorer's rule, so one row prints one number on every page. Build and browser run the same grammar, so the default is static and every setting is live, including live table cells. With `by`: `"formula": {"dc": {"value": "..."}, "whole": {...}, "adds": null}`. `"show": {"control": "stop"}` turns a row off at other stops. `"segments": [{"label": "Network", "value": "now.chat.network", "modeled": true, "word": "modeled"}]` draws the thin segmented bar in the detail, each part marked measured or modeled, or by its `word`.
**`fields`**: `{"share": {"formula": "value / region * 100", "digits": 2}}`, per row, also over `value`, `low`, `high`, for sentences and table columns; they make the Reading live.
**`also`**: `[{"claim": "dem-016", "label": "Server share of commercial sales", "say": "about {display}"}]`, printed in the detail with its receipt and in the Table view.
**`table`**: `{"columns": [{"label": "Wh", "field": "display"}]}`; fields: `label series panel column setting value low high text display unit year end source boundary claims`, a `fields` name, or a `cols` name. Or a pivot: `{"by": ["series", "year", "end"], "across": "panel", "labels": {"series": "Company"}}` (one row per group, one column per panel or series, claims last).

## On a page, outside a plate
Bench row: `<!-- bench:ai-same-hour --><!-- /bench:ai-same-hour -->` fills with that plate's default Reading, its figure on a thin ruler, and a link, from any page. Its plate must have a definition; it needs no `--page` of its own.
Claim figure in prose, hero, or Key Facts: `<span data-pour="dem-058">x</span>` fills with the claim's display at build. `data-field`: `display`, `text`, `value` (the middle figure alone, for a band), `unit`, `year`, `limit`, `status` ("verified" or "partly verified", beside a band's claim id), `source` (on an `<a>` also sets the href). A partly claim also needs `<span data-pour="dem-067" data-field="limit">x</span>` on the page, or the build fails. Pull figure: `<aside class="pull"><span class="pull-value" data-pour="dem-067" data-field="text">x</span> <span class="pull-unit" data-pour="dem-067" data-field="unit">x</span><span class="pull-label">Average rate change, PGE's territory</span><a class="receipt" data-pour="dem-067" data-field="source" href="#">x</a></aside>`.

## Numbers in prose, and the number audit (11/05/2026)
A figure in a sentence is a claim mark (`<a class="cr" data-claim="id">`), a poured figure, or a receipt; `scripts/pour_claim_refs.py` checks that every digit in a mark is in the claim's value, low, high, date, or derived text.
`scripts/number_audit.py` lists what is left, as a report and never a gate. It sets aside, with the reason on every row of its JSON: ordinals, document numbers (`Order No. 26-239`, and one inside link text such as `NIST AI 600-1`), box numbers (`Box 2.1`), product names (`Veo 3`), clock times (`1:28 PM`), license versions (`CC BY 4.0`), a year in a table, row, or figure label, a year in a title or citation, and site dates.
**Spelled counts stay unmarked.** A count written in words ("two million", "a thousand") is never wrapped in a mark, and the pour does not look for it. The rule: a claim marked or cited in the same sentence covers a spelled count in that sentence, and the audit sets it aside as `spelled_count_in_marked_sentence`. A spelled count in a sentence with no claim of its own stays open in the audit, so give the sentence a claim or reword it. Digits are never covered this way: a typed digit needs its own mark, or the audit lists it.

## Page script
`plate.register(id, {render, defaults})`. `defaults` overrides a control's default (bad values throw). `render(ctx)` runs on load, setting, resize, and selection, instead of the kit's drawing. Most plates need none.
`ctx.inputs` (write model results here, then call `ctx.auto()`: formula rows, marks, fields, and the Reading follow), `ctx.auto()`, `ctx.reason` (`init`, `state`, `size`, `select`), `ctx.state`, `ctx.data`, `ctx.plot`, `ctx.key`, `ctx.rows`, `ctx.reading(text)`, `ctx.readout(value, unit)`, `ctx.fact(text)`, `ctx.segments([{label, value, hollow}])`, `ctx.setRow(key, {frac, lo, hi, text})` (places a row by hand; `ctx.frac(value, group)`). The model's own shape stays intact:
```js
plate.register('ai-same-hour', { render(ctx) { ctx.inputs.now = compute(ctx.state, ctx.inputs.m, ctx.inputs.a); ctx.auto(); } }); // "now" is an input; rows read now.chat.total
```
`plate.draw` for a custom plot: `frame(plot, minHeight)` gives `{g, W, H}`; `inner(g, W, H, {top, right, bottom, left})`; `scale('linear'|'log', domain, range)`; `axes`, `chart`, `lines`, `multiples`, `add(parent, tag, attrs)` (`text` sets textContent), `fmt(n)`. Draw only when `ctx.reason !== 'select'` and `ctx.plot.clientWidth` is not 0. Selectable marks carry `data-row="key"`.

## Added after the first visual critique (11/04/2026)
- Value cells: `15 (9.3 to 24) Wh` prints as `.ladder-num`, `.ladder-unit`, and `.ladder-tag`, same words; with scripts, `28,740 Wh` and `240 to 320 million liters` split the same way. A row with no mark gets `.is-gap`.
- Detail: notes and `also` figures go in `details.plate-more` ("How this is modeled", or "About this figure" for a reported row); chips show the selected row's and its `also` receipts, the first six, then a button to the list. A page script can still set `ctx.data.cites`.
- Instrument rows take `"scale": "log"` with a `"domain"`; say so in the subtitle. A row hidden by a page script is skipped by the arrow keys.
- A page script may move rows out of the plot (`moveRecord` in `data-centers.js`): they keep selection; give the plot `aria-owns`.
- Multiples name every line at its end when a company is picked and a cell is over 240px wide; `spread` keeps names apart.
- Matrix bars draw only where a cell's figures share a unit.
- Rail pages: `.disclosure-grid.rail-details` holds `<details class="disclosure"><summary><h3>Title</h3><span>A full sentence.</span></summary><div class="rail-body">...</div></details>`. `theme.js` opens a closed disclosure for a deep link on every page.

## Added after the second visual critique (11/04/2026)
- Ghosts: a row with nothing at the current stop of `by` stays on the plot, in both views, as `.is-ghost`: `aria-disabled`, a 40 percent label, no mark, the plate's `not_counted` words, and no stop for arrows, a press, or a hover. A selected row that turns to a ghost gives the selection back to the default row. It replaces `plot.fold` and the foot sentence, which are gone. The Table view lists every counted row by stop, as ever.
- Count: the kit sizes the squares (largest at which every row fits, rows of 25). A row past `cap` draws none and prints "Too large to draw: N fields of cap squares." `plate.register(id, {countParts(r, unit, inputs, state)})` may split a row's squares: return `[{cls, hollow, n}, {gap: true}, ...]`, or null for the plain row.
- Segments: `"at": ["stop", ...]` on a segment limits it to those stops of `by`, so the bar and list add up to the readout. Build and browser filter the same way. `ctx.segments` is gone.
- Receipts: a row's first claim opens under the chips in the Sources view on load, on selection, and on a setting change, ready when a reader goes there; Escape or the chip closes it. A chip pressed moves focus to the receipt (a group named "Source", brought into view), and Escape returns to the chip. It used to open at the foot of the detail, past the fold, with focus left behind.
- Chips: one per `short` publisher with a count. Followers stay unhidden with `.is-extra`, so `.receipt:not([hidden])` still lists the selection's claims. The Reading view counts them by status in `.plate-tally`, "This row: 9 verified, 4 partly verified; 46 sources on the plate" ("This year" on a drawn plot, "This cell" on a matrix), a button that opens Sources; the tab reads "Sources (46)" for all the plate's receipts, so the line names both counts.
- Reading: `plate.readingInto(node, text, figure)` marks with `<b>` the first sentence holding the readout's figure, whole. In `.plate-detail` that sentence keeps the Reading's face and heading ink and the rest is body; the text is unchanged for a copy or a screen reader. A page script's own detail calls it (Explorer).
- Shared ground: `.is-flip` turns the name back when the band's end is past 0.6 or when the name would not fit between the band and the plot's end. A strip or rail row that scrolls takes `.is-cut`, a 24px fade at its right edge, while more waits past it.
- `reading_for: {"Series": "template"}` gives one series its own `reading_group` sentence; a row's `cites` then gives its receipt.
- `ctx.setRow(key, {off: true, text})`: a figure the ruler cannot hold, in words, with no mark and no `.is-gap`.
- A page script may change a one-ruler plate's axis: assign `scale` and `domain` on `ctx.data.plot`, call `ctx.auto()` again, place non-formula rows with `ctx.setRow`, and rebuild `.ladder-grid` and `.ladder-axis`.
- `measures` (11/05/2026, `dc-climate-counties`): any JSON a page script needs, copied into the plate's data with every claim id in it turned into `[id, value, low, high]`. Each id must already be a receipt (a row's `claim`, `claims`, or `cites`), so a setting the kit does not know (here the measure) still shows only claimed figures; the build fails otherwise. Without scripts the plate shows its own default, as ever.
- Script and page budgets live in one place, `tests/budgets.json`. They warn near and over the number and never fail a test.

## Keyboard, screen readers, print, and the clipped zones (11/04/2026)
**The plot is a list box, or a grid when it is a matrix.** A plot is one Tab stop holding a set of choices of which exactly one is selected, and picking one changes the detail beside it. That is a single-select list box with selection following focus, and a two-axis matrix is the same thing as a grid. The alternative, a row of buttons, was rejected: it would put 12 to 25 Tab stops inside each plate on a page with up to 11 plates, and a button does not say which one is selected.
- Roles: `listbox` with `option`, or `grid` with `row`, `rowheader`, `columnheader`, and `gridcell`. Focus stays on the plot and `aria-activedescendant` names the selected row or cell, because a row of a drawn plot is an SVG group that cannot hold focus well, and the ladder and the drawn plots should behave alike. Ruler captions become `group` labels, so with two rulers the ruler's name is said on the way into its rows.
- Keys on a list box: Right or Down is next, Left or Up is previous, Home and End are the ends, and it stops at both ends. Both axes work so a reader never has to know which way a plot runs; `aria-orientation` is `horizontal` on `lines` and `multiples`, where years run across. Keys on a grid: arrows move one cell and stop at the edges without wrapping, Home and End go to the ends of the row, Ctrl+Home and Ctrl+End to the corners. On both: Enter or Space brings the Reading view forward; Escape closes the receipt, then restores the default; Alt, Ctrl, and Meta combinations stay the browser's. The selected row scrolls into view, since focus does not move.
- What is said: an HTML row's name is its own text. A drawn band has no words, so `plate.js` names it with the Reading for that key; other cells of small multiples drawing the same key are `aria-hidden`, so one option stands for all of them. `plate.js` also sets `role="none"` on every SVG group between the `svg` and a band, a page script's drawing included: Chrome exposes an option under a plain `g` as a `group`, which keeps its name and loses its selection. `scripts/a11y_check.js` reads the browser's accessibility tree to hold this. After a pause the `output` region speaks the Reading, except when focus is on a drawn plot, whose band has just said it.
- Tabs: `tablist`, `tab`, `tabpanel`, with roving `tabindex`. The anchors stay anchors, so with no script the strip is a jump list. A hidden panel is `display: none`, so nothing in it takes focus. Enter arrives as the link's own click and Space is handled once, on keydown.

**No zone is cut.** `.plate.is-live` has a least height (`--plate-h` runs the first plate to the window's foot), not a height. A claim or detail longer than that grows the plate, in the page's own scroll, so no text meets a cut edge, and there is no second scroller, no fade, and no extra tab stop. The plot keeps its own height and aligns to the top, so its axis stays on the first screen when a zone beside it runs long; the view in the detail panel is `position: sticky`, so the Reading stays beside a tall plot. A drawing that needs more than the plate gives sets the plot's `min-height` itself (`frame`). What still runs long is a Reading view with a long sentence, or a page's own record moved under it, and the cure for those is the words.

**Print and motion.** The plate grid sits under `@media screen`, so print always stacks and nothing can clip it. Print frames each plate and shows every panel, every view, every table, every disclosure's body, and every ghost row; controls, chips, and the More assumptions settings stay off the paper on purpose, since the setting line states what is shown. Under reduced motion every transition and animation goes to 0ms, including the `is-entering` fade and the needle's stroke.

**High Contrast.** A transparent border is forced to a visible ink and a background vanishes, so `site.css` gives selected tabs and options `Highlight` and the rest `Canvas`, and keeps marks in their own ink with `forced-color-adjust: none`.

**Checks.** `node scripts/a11y_check.js --out FOLDER` runs axe-core on each tab panel in both themes with disclosures open and each plate's Sources and Table views shown, and exits 1 on a serious or critical issue. `node scripts/page_check.js --page plate` holds the keys, the names, and every Energy orange pairing's contrast without a browser.

## Outputs, the address, and the Council Briefing (11/05/2026)
**A figure's words.** One rule, `fig` in `plate.js` and `rounded` and `number` in `build_plates.py`: two significant figures, three at 99.5 and up, a row's `digits` over both, and no trailing zero: `3 (2.4 to 6)`, never `3.0 (2.4 to 6.0)`. A template's own `{x:.1f}` is its author's choice and prints what it asks.

**What leaves a plate.** `.plate-out`, in `.plate-actions` beside Copy and Reset, is one row of three text buttons (three more boxes would stack the panel's first screen). All of it runs in the reader's browser through `plate.save(name, text, type)`, a `Blob` and an `a[download]`; nothing goes to a server. Hidden without scripts, and in print.
- **Print this plate** names the plate on `<html data-print-one="ID">` and marks it `.is-print-one` until `afterprint`, so Ctrl+P on its own still prints the page. The sheet is a one-line head (the page's name and the eyebrow, then the guard line and the checked date), the title at the settings, the plot, the Reading, the setting line, the Table, and Sources in two columns with no quotes, boundaries, or arithmetic, which stay on the site under the claim id; the foot line closes it. A plate with many table rows or receipts runs to more sheets, and its lines stand at its start and end, not on each. A date comes from `[data-checked]` around the plate, else the band's "Sources checked" figure.
- **Download CSV** writes `ID-MM-DD-YYYY.csv`: the Table view as it shows at these settings, then `claim_ids`, `status`, and `limit` for each line, then two lines, `settings` and `checked`. A byte-order mark tells Excel it is UTF-8.
- **Download SVG** shows only while the plot holds a `.plate-svg` (`lines`, `multiples`, and a page's own drawing; a ladder, bars, or instrument is HTML, and the printed sheet is its picture). `ID-MM-DD-YYYY.svg` has `<title>` the claim sentence, `<desc>` the guard lines and claim ids, a `<rect>` of the plot's ground, and each mark's computed paint and type as its own `style`, so it stands alone in whichever theme it left (a `<style>` of tokens would have had to copy the kit's rules too). Fonts are named, not embedded.

**The address.** `<html data-address="none">` is for a page whose readers type their own figures: `writeQuery` returns at once, `copyReading` omits the link, and `readState` takes a stop or a row from a link but never a range or number value. Other plate pages keep their settings in the address, since the home questions and bench links rely on it, and any plate with a range or number control prints one sentence under its actions saying so. On such a page the title follows the settings: moved off the defaults it is the Reading's first sentence, because a packet may not state a figure its plot has left. `printOne` does the same for the sheet on any page, and gives the title back after.

**For a page's script.** `plate.read(id)` gives `{id, title, state, selected, changed, settings: [{name, label, word, changed}], receipts}`; `plate.reset(id)` puts a plate back.

**Paper.** A plate's rows keep their columns on paper (the phone layout is `@media screen` now, since a Letter sheet with wide margins is under 720px). A drawing keeps its own proportions at the sheet's width. No focus ring prints.

**The briefing.** `site/briefing/index.html` is hand-written outside its `briefing:` markers. Plates reach it as copies of their built blocks, whole, since a block holds its data and receipts, so the page fetches nothing and every plate check still holds there. Only the one-level pages' plates come: `../` paths resolve unchanged, and a link to the source page's own ids or subpages is rewritten. A section is framed by a real `<table role="presentation">`, a `display: block` on screen, because Chrome repeats a `thead` and `tfoot` on every printed page and does not repeat CSS table groups; so the guard line and foot line are real text on each sheet. The Energy page's script and sheet do not come with its plates: there, they are the bars the build draws and the list of deadlines. **The PDF.** `briefing/atni-energy-briefing.pdf` is the default packet, the first plate each page lists and every checklist at their defaults, printed by headless Chrome from this page's own scripts (`scripts/build_briefing_pdf.py`); each sheet's guard line says "Default settings" and the day it was built, its links are the public site's, and its cover says what it holds and where the claim ids are, and its Keywords carry a hash of the packet's HTML and of the stylesheets, scripts, and fonts it is drawn with, for `--check`.

**Run order after a plate changes:** `build_plates.py`, `pour_claim_refs.py`, `build_index.py`, `build_share_cards.py` (if a lead plate's title moved), `build_briefing.py`, `build_briefing_pdf.py`, `add_page_meta.py`, then `validate_public.py`. `tests/test_index_briefing.py` fails with the fix if the manifest, a card, or the briefing has fallen behind, and `tests/test_briefing_pdf.py` if the PDF has.

**`site/data/index.json`** lists each plate (id, page, eyebrow, title at its defaults, kind, controls, claim ids, checked date, path), each claims cluster (path, count, verified, partly), and each data file (path, schema, tier, builder); the tier is the file's own, `null` when the file names none. `validate_public.py` fails if a listed path is gone, a listed JSON file does not say T0, or a plate is not listed.
